# Payroll Management System

A mobile-friendly payroll management web app built with React + Vite. It allows users to:

- enter payroll details
- edit existing payroll records
- delete records
- download employee payroll data as an Excel file

## Features

- Responsive design for mobile and desktop
- Payroll form with employee details and salary breakdown
- Automatic net pay calculation
- Edit and delete entries
- Excel export using `xlsx`
- Local storage persistence in the browser

## Tech Stack

- React
- Vite
- JavaScript
- xlsx

## Getting Started

1. Install dependencies:
   npm install
2. Run the app:
   npm run dev
3. Open the local URL shown in the terminal.

## Build for Production

npm run build

## Excel Export

Use the "Download Excel" button in the app to export all payroll records as a .xlsx file.
